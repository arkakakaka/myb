Как синхронизировать iPhone и Mac

На одном устройстве открой Настройки → Аккаунт и создай аккаунт. На втором войди с той же почтой и паролем. Без аккаунта всё хранится только на устройстве и работает без интернета.

Не пришло письмо с кодом

Проверь папку «Спам» и правильность адреса. Новый код можно запросить через минуту.

Забыл пароль

На экране входа нажми «Забыли пароль?», введи код из письма и придумай новый пароль.

Данные на одном устройстве не обновляются

Настройки → Аккаунт → «Проверить связь» покажет, доходит ли запрос до сервера. Если нет — проверь интернет, закрой myB и открой снова.

Как добавить виджет

iPhone: удерживай палец на экране «Домой» → «Изменить» → «Добавить виджет» → myB. Mac: правый клик по рабочему столу → «Изменить виджеты» → myB.

Где инструкция

В приложении: Настройки → «Как пользоваться». Ещё её открывает меню профиля, клавиша «?», а на Mac — меню «Справка» → «Как пользоваться myB».

Как перенести все повторы задачи сразу

Перетащи в календаре один раз повторяющейся задачи на новое время или день — внизу появится подсказка. «Перенести все» сдвинет так же всю серию, «Отменить» вернёт как было.

Как сменить язык

Настройки → Внешний вид → Язык. По умолчанию myB говорит на языке устройства.

Как сохранить копию данных

Настройки → Интеграции и импорт. Файл можно потом загрузить обратно на любом устройстве.

Как удалить аккаунт

Настройки → Аккаунт → «Удалить аккаунт». Аккаунт и все данные на сервере удаляются сразу и навсегда. Данные только на этом устройстве удаляет кнопка «Удалить с устройства».

Support

Answers to common questions about myB. Didn’t find yours? Write to the email at the bottom of this page.

How to sync iPhone and Mac

On one device, open Settings → Account and create an account. On the other, sign in with the same email and password. Without an account everything stays on the device and works offline.

The email with the code didn’t arrive

Check your Spam folder and the address you typed. You can ask for a new code after a minute.

I forgot my password

On the sign-in screen, tap “Forgot password?”, enter the code from the email and choose a new password.

Data doesn’t update on one device

Settings → Account → “Check connection” shows whether requests reach the server. If they don’t, check your internet connection, then quit myB and open it again.

How to add a widget

iPhone: touch and hold the Home Screen → Edit → Add Widget → myB. Mac: right-click the desktop → Edit Widgets → myB.

Where is the guide

In the app: Settings → How to use. You can also open it from the profile menu, with the “?” key, or on a Mac from Help → How to Use myB.

How to move all repeats of a task at once

Drag one occurrence of a repeating task in the calendar to a new time or day — a hint appears at the bottom. Move all shifts the whole series the same way, Undo puts it back.

How to change the language

Settings → Appearance → Language. By default myB uses your device’s language.

How to save a copy of my data

Settings → Integrations and import. You can load the file back on any device.

How to delete my account

Settings → Account → “Delete account”. The account and all its server data are deleted immediately and permanently. “Delete from device” removes the data on this device only.
